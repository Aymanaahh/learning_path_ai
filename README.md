# 🎓 Learning Path AI — Streamlit App

This project is a no-API-key, an interactive learning-path Streamlit application that accepts a course outline and allows users to specify a topic they want to study. The application breaks the selected topic into relevant subtopics and provides suggested YouTube videos and web resources to help users learn and cover the topic effectively. It also generates hands-on assignments and practical activities to help users apply their knowledge and strengthen their understanding.

## Features

- Paste a complete course outline.
- Enter the specific topic you want to learn.
- Break the topic into structured subtopics.
- Generate a YouTube search link for every subtopic.
- Discover public web resources without an API key.
- Generate hands-on assignments for every subtopic.
- Download the generated learning plan as a `.txt` file.
- Deploy directly to Streamlit Community Cloud.
- Test from Google Colab using a Cloudflare Quick Tunnel.

## Important architecture note

This version intentionally does **not** call Cloudflare Workers AI because Workers AI's REST API requires a Cloudflare API token and Account ID.

Instead, the app uses:

1. **Built-in Python logic** for the initial topic/subtopic decomposition.
2. **DuckDuckGo's public HTML search page** for resource discovery.
3. **YouTube search URLs** instead of requiring a YouTube API key.
4. **Cloudflare Quick Tunnel (`cloudflared`)** only when you want a public URL while testing the Streamlit app from Google Colab.

This gives you a zero-API-key prototype.

## Deploy to Streamlit Community Cloud

1. Create a GitHub repository.
2. Put these files in the repository root:
   - `app.py`
   - `requirements.txt`
   - `README.md`
3. Push/commit the files.
4. Open Streamlit Community Cloud.
5. Choose **Create app**.
6. Select your repository and branch.
7. Set the main file to `app.py`.
8. Click **Deploy**.

No Streamlit secrets are required by this version.

## Limitations

Because this is a zero-API-key prototype:

- Subtopic generation is template/rule based rather than generated by an LLM.
- Resource discovery depends on public search results.
- YouTube links are search links rather than guaranteed direct video recommendations.
- Search engines can change their HTML structure or rate-limit automated requests.
- For a production-quality AI tutor, an LLM API or your own hosted model would provide better topic decomposition and personalized assignments.
