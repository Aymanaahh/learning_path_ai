# 🎓 Learning Path AI — Streamlit App

Learning Path AI is a **no-API-key, interactive Streamlit learning-path application**. It accepts a course outline and lets a user choose a topic to study. The app then builds a structured learning path containing subtopics, learning objectives, web resources, YouTube search resources, hands-on assignments, a self-assessment MCQ quiz, and a mini project.

The application is designed to be simple to run locally, test from Google Colab, expose temporarily through a Cloudflare Quick Tunnel, or deploy to Streamlit Community Cloud.

---

## ✨ Features

- Paste a complete course outline.
- Enter or select the specific topic you want to learn.
- Break a selected topic into structured subtopics.
- Provide learning objectives for subtopics.
- Assign difficulty/level and estimated learning time.
- Generate a YouTube search link for every subtopic.
- Discover public web resources without an API key.
- Use curated authoritative resources for supported domains where available.
- Generate hands-on assignments and practical activities.
- Generate a **5-question multiple-choice self-assessment quiz**.
- Automatically grade MCQ answers.
- Display quiz score and percentage.
- Show correct answers and explanations after submission.
- Use a **70% recommended pass level** for self-assessment.
- Keep the learning experience **fully self-paced** with no timer or forced sequence.
- Download the complete learning path as a `.txt` file.
- Download the complete learning path as a `.pdf` file.
- Run the application in Google Colab.
- Expose the Colab Streamlit app through a Cloudflare Quick Tunnel.
- Deploy the application to Streamlit Community Cloud without Streamlit secrets or an API key.

# 🧠 Quiz and Self-Paced Learning

The app now includes an MCQ-based self-assessment instead of an open-ended quiz.

For each generated topic, the application provides:

1. Five multiple-choice questions.
2. Four answer choices per question.
3. A **Submit Quiz** button.
4. Automatic scoring.
5. A percentage score.
6. Correct/incorrect feedback.
7. The correct answer.
8. A short explanation for each question.

### Self-paced behavior

The quiz is intentionally **self-paced**:

- There is no countdown timer.
- There is no required completion time.
- The user can study the resources and assignments first.
- The user can answer questions in their own order.
- The user can submit the quiz when ready.
- The user can review incorrect answers and try again.

A score of **70% or higher** is treated as the recommended pass level for self-assessment.

### Important quiz architecture

The MCQ system is designed to work **without an external AI/API service**. The answer keys are defined in the application's deterministic question banks, so grading does not depend on an LLM response.

The question bank is selected according to the detected domain, such as:

- Machine Learning
- Programming
- Database
- Data Analysis
- Web Development
- Networking
- Cybersecurity
- Software Engineering
- General learning

For unusual or unsupported topics, the application falls back to a general learning/self-assessment question bank.

> **Note:** Because this version does not use an LLM API, the MCQs are domain-based rather than dynamically generated by an AI model for every possible topic.

# 🔑 Important Architecture Note

This version intentionally does **not** call Cloudflare Workers AI because Workers AI's REST API requires a Cloudflare API token and Account ID.

Instead, the application uses:

1. **Built-in Python logic** for initial course/topic extraction and topic/subtopic decomposition.
2. **DuckDuckGo's public HTML search page** for public resource discovery.
3. **Curated authoritative web resources** for supported learning domains.
4. **YouTube search URLs** instead of requiring a YouTube API key.
5. **Deterministic MCQ banks** for automatic quiz grading without an API.
6. **ReportLab** for PDF generation.
7. **Cloudflare Quick Tunnel (`cloudflared`)** only when a temporary public URL is needed while testing from Google Colab.

This keeps the application a **zero-API-key prototype**.

# ⚠️ Limitations

Because this is a zero-API-key prototype:

- Subtopic generation is template/rule based rather than generated by an LLM.
- Resource discovery depends on public search results.
- DuckDuckGo's HTML structure can change.
- Search engines can rate-limit automated requests.
- YouTube links are search links rather than guaranteed direct video recommendations.
- MCQs use deterministic domain-specific question banks rather than AI-generated questions for every individual topic.
- The automatic quiz grading only evaluates the predefined MCQ answer choices.
- The quiz is a learning aid and not a formal academic assessment.
- Progress is currently session-based rather than a persistent user account system.
- There is no database-backed user progress history.
- Assignment work is not automatically graded.
